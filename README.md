# Text Light Effect

A stunning CSS text light/glow effect animation.

## Features

- Glowing text animation
- Smooth light sweep effect
- Pure CSS implementation

## Tech Stack

- HTML5
- CSS3 (Animations & Keyframes)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/ayushpratap27/Text-Light-Effect.git
   ```
2. Open `index.html` in your browser.
